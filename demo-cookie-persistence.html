Vector Support - Cookie Persistence Demo

Cookie Persistence Feature

This demo shows how the Vector Support Embed now stores bot nsec and chat history in cookies, allowing users to maintain their session even after page refresh.

Key Features:

  • Bot nsec persistence: The bot's private key is stored in a cookie, maintaining the same identity across page refreshes
  • Chat history persistence: All messages are saved to cookies, so conversations continue seamlessly
  • Automatic saving: Messages are saved automatically after each send/receive
  • 30-day expiration: Cookies persist for 30 days by default
  • Instance isolation: Multiple embed instances on the same page have separate cookies

How to Test

  1. Click "Load Vector Support Embed" to initialize the support system
  2. Click the "Get Support" button that appears (bottom right of page)
  3. Send a test message in the chat window
  4. Refresh the page - your messages and bot identity should persist!
  5. Check the console logs to see cookie operations
